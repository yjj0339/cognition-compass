# 认知罗盘 · Cognitive Compass Pro

> **线上地址：<https://yjj0339.github.io/cognition-compass/>**（v3 专业版）

对标国际标准测验体系的七维认知评估，约 18 分钟。维度框架采用 **CHC 认知能力模型**（WAIS 等临床量表的底层分类），题型逐一对照世界级测验范式：

| 维度 | 对标范式 | 内容 |
|---|---|---|
| 流体推理 | 瑞文 APM | 6 道多规则矩阵（数量/位置/拉丁方/笔画累加/算术/异或叠加） |
| 视觉空间 | Shepard-Metzler / Vandenberg-Kuse | 4 道 3D 心理旋转（等轴投影、镜像手性干扰） |
| 定量推理 | ICAR 数字系列 | 二阶等差、质数平方、交错数列、外观数列 |
| 言语推理 | GRE/MAT/ICAR | 类比、语义精析、平行论证结构 |
| 逻辑推理 | Wason 1966 | 抽象选择任务、假言连锁逆否、三段论 |
| 概率与理性 | CRT / 卡尼曼-特沃斯基 / CART | 调和平均、贝叶斯、辛普森悖论、蒙提霍尔、合取谬误、期望值 |
| 工作记忆 | n-back (CBS) + 倒叙广度 | 2-back 实时监控任务 + 数字倒叙 6/7 位 |

**质量保障**：3D 旋转题的构型同构性由代码枚举全部 24 个三维旋转做数学断言（正确项必同构、干扰项必异构）；`?__auto=1` 自动真实点击走完全部 30 步（含 n-back 按键模拟）；`?__selftest=1` 题库与计分上下界断言。每题标注难度星级与文献通过率。

单文件 `index.html`，零依赖离线可用；结果页含七维雷达图、估算百分位、Brier 元认知校准、达克效应自评对比与逐题深度解析。

## 测什么

| 维度 | 范式来源 | 测的核心问题 |
|---|---|---|
| 认知反思 | 认知反思测验 CRT（Frederick, 2005） | 能否压住"第一反应"去验证 |
| 逻辑推理 | Wason 选择任务（1966）、三段论、条件推理 | 只按规则推导，不被画面感带走 |
| 概率直觉 | Kahneman & Tversky 实验 | 基础率、样本量、独立性 |
| 偏差识别 | 幸存者偏差、沉没成本、框架效应等 | 在真实情境中认出思维陷阱 |
| 模式推理 | Raven 式矩阵、数列推理 | 抽象规则的发现能力（流体智力） |
| 工作记忆 | 数字倒叙广度 | 脑中"草稿纸"的容量 |

## 超越普通"智商测试网页"的测量设计

- **直觉陷阱项**：每道选择题都设有文献记载的高频错误选项，答错可诊断思维模式而非单纯"不知道"。
- **元认知校准**：每题作答后报告把握程度，用 Brier 分数计算"确信度 × 正确率"的匹配度——测"知道自己什么时候知道"。
- **达克效应对比**：开场自评百分位 vs 实测百分位，量化自我认知偏差。
- **作答质量监控**：注意力检测题 + 反应时分析，识别随意作答与"过快直答"。
- **逐题深度解析**：24 题每题附范式出处与思维机制讲解，测完即是一次认知训练。
- **估算常模**：百分位由文献报告的各题通过率拟合映射，页面明示"估算、非临床诊断"。

## 技术

单文件 `index.html`，零依赖、零构建、离线可用；进度自动保存（localStorage）；手机优先的浅色学术风 UI。

本地预览：直接双击 `index.html`，或 `node tools/server.js`（局域网地址打印）。
